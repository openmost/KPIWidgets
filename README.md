# KPI Widgets
Display KPI in widgets on your Matomo dashboard !

## Description
With KPI Widgets plugin, you'll be able to display the most important KPI on your Matomo dashboard the easiest way !

Each widget shows the current value with an evolution indicator compared to the previous period, using the Matomo 6 design.
